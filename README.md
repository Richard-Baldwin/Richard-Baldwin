### About Me

I'm a developer focused on **low-level systems programming**, **security research**, and **autonomous robotics**. I work across the full stack from kernel drivers and Windows internals to reinforcement learning systems for competitive robot soccer.

Currently contributing to open-source remote administration tooling and building AI-driven control systems for RoboCup SSL robots.
